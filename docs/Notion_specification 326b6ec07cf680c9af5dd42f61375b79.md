# 幼児向け　スマホアプリ

**1-2歳向け知育アプリ「たのしい！プレイタイム」要件定義書**

**1. プロジェクト概要**
• **コンセプト:** 「触ると動く・音が鳴る」という直感的なフィードバックを通じて、1歳児の好奇心を刺激する。
• **ターゲット:** 1歳2か月〜2歳前後の乳幼児、およびその保護者。
• **プラットフォーム:** Flutter Web (PWA)。iPhoneの「ホーム画面に追加」での利用を推奨。

**2. デザイン・UI/UX指針**
• **ビジュアルスタイル:**
    ◦ 温かみのある3D質感（ソフトビニールや木製おもちゃのような質感）。
    ◦ パステルカラーを基調とした高コントラストな配色。
• **UXルール:**
    ◦ **テキストレス:** 幼児向け画面には文字を置かない（アイコンと音で理解させる）。
    ◦ **誤操作防止:** 画面端の「ホームボタン（南京錠アイコン）」は**3秒間の長押し**でのみ作動。
    ◦ **連打対応:** 高速なタップに対しても、音が不快に重なりすぎないよう制御。

**3. 画面別機能要件
3.1 ホーム画面（ポータル）**
• **背景:** 黄色〜ピンクのグラデーション、シャボン玉や虹の装飾。
• **中央要素:** 3Dのクマとおもちゃのメインビジュアル。
• **操作:** 「あそぶ」ボタンを押すと、ゲーム選択画面（グリッド表示）へ遷移。

****

**3.2 ゲーム選択画面（ポータル）**
2×2のグリッドレイアウトを指定。
文字（Text）を排除し、アイコン主体のデザインにする。
パステルカラーや原色を使い、1歳児が認識しやすいコントラストにする。
ゲーム選択は、ピアノ、落書き、リモコンの３つ
 将来性: 今後ゲームが増えることを想定し、選択画面はスクロール可能な GridView で実装。

**3.3 ピアノ**
• **構成:** 画面いっぱいに広がる8つの3D鍵盤（ドレミファソラシド）。
• **デザイン:** 鍵盤に「ドレミ」の文字を刻印（木目調または光沢感）。背景には浮かぶ音符。
• **機能:**
    ◦ マルチタッチ対応（和音が弾ける）。
    ◦ タップ時に鍵盤が沈み込み、上部にキラキラや音符が飛び出す。
****　◦ 画面左上ボタンを1秒くらい押すとゲーム選択画面に遷移

**3. 4らくがき（虹色の線）**
• **構成:** 全面キャンバス。
• **機能:**
    ◦ 指でなぞった軌跡が「虹色」の太い線になる。
    ◦ 指を離した瞬間に「星」や「ハート」のスタンプが表示される。
    ◦ 画面下部の「ゴミ箱」ボタン長押しで全消去。
　◦ 線の色に合わせて少しずつ音程が変わる「キラキラした描画音」が持続的に鳴るようにしました。そして指を離した瞬間に、スタンプの出現と同時に高い音程の「ポンッ」という別のリリース音が鳴るように設定
　◦ 画面左上ボタンを1秒くらい押すとゲーム選択画面に遷移

**3.5 リモコン（音あそび）**
• **構成:** 0〜9の大きな数字ボタン。各数字の横に動物の小さなアイコン。
• **機能:**
    ◦ 数字タップでその数字を読み上げる（または動物の鳴き声）。
    ◦ 「ピンポーン」「ブッブー」といった生活音をランダムに配置。
　◦ ボタンを同時に押しても、音が鳴る仕様にする
　◦ 画面左上ボタンを1秒くらい押すとゲーム選択画面に遷移

**4. インフラ・技術要件項目内容開発環境**Flutter (Dart), VS Code**デプロイ先**GitHub Pages (HTTPS必須)**PWA設定**`manifest.json` により全画面表示、オフライン起動対応**音源管理**`audioplayers` パッケージ。起動時に全音源をプリロード**エフェクト**`lottie` または `SimpleAnimations` による3D風の動き
